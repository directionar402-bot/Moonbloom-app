# Moonbloom ☾

My personal wellness, training, nutrition and manifestation universe.

A single-page web app that installs on your phone like a native app (PWA).
Everything you log is saved privately in your own browser on each device.
Use **Settings → Your data → Export backup** to move data between devices.

## Files
- `index.html` — the whole app
- `manifest.webmanifest` — app name, colors and icons for installing
- `sw.js` — offline support and notifications
- `icons/` — app icons
